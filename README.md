Web-map tiles (512 px WebP, XYZ; Leaflet tileSize 512, zoomOffset -1) for https://geonet-myanmar.github.io/launglon-landslides-2026/,
hosted separately so every site stays under GitHub Pages' 1 GB limit. Built by scripts/10_tiles.py in the launglon-landslides-2026 repo
(Taw Kye's by its own pipeline); do not edit by hand.

- kanpani/: Kan Pa Ni - Pa Nyit road, 13 Oct 2026, 9.5 cm
